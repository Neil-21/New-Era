# Welcome to the demo vault

This is a small, shareable example vault. Its pages demonstrate wikilinks,
properties, tasks, a Kanban board, and a database-friendly folder structure.

Start with [[Shakespeare]], [[OpenAI]], [[Anthropic]], or [[AI Shopping Features]].

> [!tip] Your files stay portable
> This vault contains ordinary Markdown. Paste an image or drop a spreadsheet
> into a note to keep it alongside the writing that uses it.
